## Instrucciones de ejecución

### Con NetBeans
1. Abrir el proyecto en Apache NetBeans.
2. Clic derecho sobre `Main.java` y elegir **Run File** (o presionar `Shift + F6`).

### Con la terminal
Requiere tener el JDK instalado. Desde la carpeta que contiene los archivos `.java`:

```bash
javac -d out *.java
java -cp out com.mycompany.main.Main
```

El primer comando compila las 4 clases en la carpeta `out`, y el segundo ejecuta `Main`.
